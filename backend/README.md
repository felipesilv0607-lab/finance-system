Backend do sistema financeiro — esqueleto inicial com Node.js e Express.

Scripts (no diretório backend):
- npm install             # instalar dependências (opcional)
- npm run dev             # iniciar em modo desenvolvimento (nodemon)
- npm start               # iniciar em produção

Endpoint de saúde:
- GET /api/health -> retorna { status: 'ok', message: 'API funcionando' }
