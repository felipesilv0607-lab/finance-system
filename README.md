# Finance System

Sistema financeiro Full Stack desenvolvido para portfólio.

## Tecnologias

### Frontend
- HTML
- CSS
- JavaScript
- React (Vite)

### Backend
- Node.js
- Express

### Banco de Dados
- PostgreSQL
- Prisma ORM

### Objetivo

Controlar receitas, despesas e fornecer gráficos financeiros para o usuário.
